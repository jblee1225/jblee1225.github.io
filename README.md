# jblee1225.github.io

Personal academic website of **Jaebeom Lee, Ph.D.** — Senior Research Scientist at KRISS.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme. Deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.

## Editing content

| What | Where |
| --- | --- |
| Home / bio / awards | `_pages/about.md` |
| Research projects | `_pages/research-projects.md` |
| Publications (BibTeX) | `_bibliography/papers.bib` |
| Research vision | `_pages/research-vision.md` |
| Presentations (BibTeX) | `_bibliography/presentations.bib` |
| Press | `_data/press.yml` |
| News on homepage | `_news/*.md` |
| Profile photo | `assets/img/prof_pic.jpg` |
| Site settings | `_config.yml` |
